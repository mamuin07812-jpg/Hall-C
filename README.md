# HALL C

Flutter starter app for English Department – Group C.

## Included
- Dashboard
- Weekly schedule
- Preparations
- Announcements
- Files
- Profile
- Admin-ready structure
- Modern Material 3 UI
- Local demo data (no Firebase secrets included)

## Open
Open this folder in VS Code, then run:
flutter pub get
flutter run

For APK:
flutter build apk --release

Firebase/Auth/Firestore/Storage/FCM should be connected using the project's own Firebase account and secrets.
